# קונצנזוס – מערכת משאלים, גישור ושיתוף ציבור חכם
## פלטפורמת דמוקרטיה חישובית בעברית (RTL) בהשראת Polis ו-Talk to the City
### מיתוג דגל: "המצפן העירוני – ערב ערב באילת"

מערכת Full-Stack מוכנה לייצור (Production-Ready) המיועדת להחליף שיח מקוטב ומתלהם ברשתות החברתיות בתהליך מובנה לאיתור **"הצהרות גשר" (Bridging Statements)** — פתרונות מעשיים הזוכים להסכמה רחבה חוצת-מגזרים.

---

## 🌟 יכולות המערכת המרכזיות

1. **ארכיטקטורה רב-זירתית (Multi-Domain Topics):**
   - **עיתונות מקומית ושיתוף ציבור:** *מצוקת החניה באילת (ערב ערב באילת – המצפן העירוני)*.
   - **גישור ויישוב סכסוכים:** *איזון בין דירות נופש (Airbnb) לאיכות החיים בשכונות הוותיקות (מרכז הגישור הקהילתי)*.
   - **ועדות ציבוריות וחלוקת משאבים:** *קריטריונים לחלוקת מלגות ותמיכות (ועדת מלגות וקרן אילת)*.
   - **ייעוץ ארגוני וניהולי:** דיאגנוסטיקה והסכמות פנים-ארגוניות (*DANBAR Consulting*).

2. **שלב הצבעה חווייתי (Tinder / Polis Card Stack):**
   - הזדהות אנונימית מהירה (Micro-Onboarding) בבחירת "כובע זיקה" (תושבים, עסקים, תיירות וכו').
   - הצגת היגד יחיד בכל פעם עם מקשי קיצור במקלדת וכפתורי מגע נגישים (`מסכים 👍`, `לא מסכים 👎`, `מדלג / ניטרלי ⏭️`).
   - מבזק תובנה מיידי לאחר הצבעה (למשל: *"84% מהמצביעים עד כה הסכימו עם היגד זה"*).
   - מגירת היסטוריית הצבעות המאפשרת לעיין ולשנות כל הצבעה קודמת.

3. **שער AI להגנה מלשון הרע וניסוח מגשר (AI Guardrail & Mediator):**
   - מנגנון הגנה המזהה בזמן אמת שמות פרטיים (PII), קללות, השמצות אישיות או התלהמות.
   - בעת זיהוי סגנון לעומתי, המערכת מפיקה הסבר מנומס והצעת ניסוח קונסטרוקטיבית, עניינית ומגשרת (עד 140 תווים) שניתנת לאימוץ בלחיצת כפתור.
   - פועל עם מודלי Gemini (`GEMINI_API_KEY`) וכולל סימולטור גישור היוריסטי אותנטי בעברית הפועל מיד ללא תלות במפתח.

4. **מנוע אלגוריתמי לקונצנזוס (Bridging Engine):**
   - **ציון גשר (Bridging Score):** $\text{Support}_{\min} \times (1 - \text{Spread} \times 0.5)$ — מאתר היגדים בעלי תמיכה גבוהה בכל הקבוצות בנפרד (מעל 60% בכל מחנה).
   - **ציון קיטוב (Divisive Score):** מזהה את סלעי המחלוקת שבהם נרשם פער עמדות חד.
   - תרשים התפלגות עמדות רב-קבוצתי אינטראקטיבי (Recharts).

5. **מחולל דו"ח עיתונאי ונייר עמדה לגישור (AI Report Generator):**
   - **תבנית כתבת סוף שבוע ל"ערב ערב באילת":** כותרת עיתונאית, ממצאי הדאטה, 3 פתרונות הקונצנזוס, ו-3 שאלות נוקבות להנהלת העירייה.
   - **תבנית נייר עמדה לוועדה / גישור קהילתי:** ניתוח ZOPA (מרחב ההסכמה האפשרי), מיפוי אינטרסים עמוקים, ומפת דרכים ליישום.
   - העתקה מוכנה לפרסום או הורדה בלחיצת כפתור.

6. **ממשק ניהול, סינון והטמעה (Editor & Admin):**
   - תור אישור ובקרת תוכן להיגדי גולשים (Approve / Reject / Edit).
   - יצירת זירות דיון חדשות כולל הגדרת קבוצות וצבעים, והזנת היגדי פתיחה.
   - מחולל קוד הטמעה (`<iframe>` עם `?embed=true`) להטמעה ישירה ב-`yomyom.net` או אתרי לקוחות.

## 🚀 הוראות הרצה מקומית

### 1. הפעלת השרת והאפליקציה

```bash
# התקנת תלויות (אם טרם הותקנו)
npm install
npm install --prefix client

# בנייה של קבצי ה-Frontend
npm run build

# הפעלת השרת (רץ על פורט 3001 ומגיש גם את קבצי ה-Frontend)
npm start
```

גש בדפדפן אל: **`http://localhost:3001`**

### 2. מצב פיתוח (Hot-Reload)

```bash
# הרצת שרת Express (פורט 3001) ו-Vite Dev Server (פורט 3000) במקביל:
npm run dev
```

גש בדפדפן אל: **`http://localhost:3000`**

### 3. הגדרת משתני סביבה (Google Gemini ו-Supabase)

ניתן ליצור קובץ `.env` בשורש הפרויקט (ראה `.env.example`):
```env
# מפתח Google Gemini עבור סינון תגובות, הצעת היגדים ומחולל דוחות
GEMINI_API_KEY=your_gemini_api_key

# פרטי פרויקט Supabase לסנכרון ענן
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your_anon_key

PORT=3001
```

## ☁️ פריסה מהירה ל-Vercel (Deployment)

הפרויקט מוגדר לפריסה מלאה ב-Vercel עם קובץ `vercel.json`:
1. **Frontend**: נבנה אוטומטית מ-`client/` ומוגש מ-`client/dist` דרך CDN עולמי מהיר.
2. **Serverless API**: מנוהל דרך `api/index.js` ומטפל בכל נקודות הקצה (`/api/*`).
3. **מסד נתונים היברידי חכם**:
   - בסביבה מקומית / VPS רגיל: מנוע SQLite ביצועי (`better-sqlite3`) עם קובץ `consensus.db`.
   - ב-Vercel Serverless: מנוע SQLite WebAssembly טהור (`sql.js`) נטול תלויות C++ מקומיות, הפועל בכל תנאי פריסה ללא שגיאות קומפילציה, עם סנכרון ל-Supabase.

## 🗄️ מבנה בסיס הנתונים (`consensus.db` ו-Supabase)

* `topics`: זירות הדיון, כותרות, ארגון יוזם, קבוצות זיקה בצבעים.
* `statements`: היגדי פתיחה והצעות גולשים, סטטוס אישור (`approved`, `pending`, `rejected`).
* `votes`: הצבעות אנונימיות מבוססות `session_id` (`1` = מסכים, `-1` = לא מסכים, `0` = מדלג).
